# Create Jira Ticket

1. Gather the request and relevant project context. Use confirmed facts; don’t invent scope, priority, or ownership.
2. Choose the closest example in `examples/` and follow its format: **Summary**, **Issue Type**, and **Description** with relevant context and acceptance criteria.
3. Keep the ticket concise and make acceptance criteria specific and verifiable. Include reproduction steps and expected/actual behavior for bugs.
4. Review the ticket for clarity and consistency. Create it in Jira only when requested; otherwise provide the finished draft.
